# Blinkit-Sales-Performance-Analysis

## 📌 Project Overview
This project analyses Blinkit's sales, customer behaviour, delivery performance, 
and marketing effectiveness using Python and Power BI.
The goal was to uncover business insights from real-world grocery delivery data
and present them through an interactive dashboard.

## 🖼️ Dashboard Preview
![Dashboard](dashboard_preview.png)

## 📊 Dataset
The dataset contains 8 CSV files with 5,000+ orders:

| File | Description |
|------|-------------|
| blinkit_orders.csv | Order details, payment, delivery status |
| blinkit_customers.csv | Customer segments and location |
| blinkit_order_items.csv | Products per order, quantity, price |
| blinkit_products.csv | Product categories, brands, margins |
| blinkit_delivery_performance.csv | Delivery time and delay reasons |
| blinkit_customer_feedback.csv | Ratings and sentiment |
| blinkit_marketing_performance.csv | Campaign performance and ROAS |
| blinkit_inventory.csv | Stock and damaged goods |

## 🔧 Tools Used
- Python (Pandas, NumPy, Matplotlib, Seaborn)
- Power BI
- Google Colab
- Git & GitHub

## 📈 Key Findings
- 💰 Total Revenue: ₹11.01M across 5,000 orders
- 🛒 Average Order Value: ₹2,200
- 🥛 Dairy & Breakfast was the top revenue category (₹0.64M)
- 🚚 69.4% of deliveries were completed on time
- 😐 Customer sentiment was almost equally split — only 32% positive
- 📧 Email was the highest revenue-generating marketing channel
